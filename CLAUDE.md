# CLAUDE.md — PromptShield (budget mode)

Student minor project: PromptShield, a layered firewall against prompt injection (English, Hindi, Hinglish).

- The plan is `PROMPTSHIELD_BUILD_PLAN.md`. Read sections 1–4 and `PROGRESS.md`; read a prompt's section 5 entry only when the user names that prompt (P1–P10, F1–F3).
- Do only the named prompt. Write all its files in one pass; minimal file reads; no web fetching; no extra features.
- Decisions are pre-filled in section 2. Ask only if something there is blank or impossible, all in one message with numbered options and a recommendation.
- Don't run installs, training, servers or long jobs; give the user the command.
- Never hard-code or print secrets; never train or tune on test data; never invent results.
- Final message ≤ 10 lines. Append one line to `PROGRESS.md` per prompt.
